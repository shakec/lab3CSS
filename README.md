# Reflection Questions

## 1. What challenges did you face when refactoring your code to use Bootstrap?
Man, using Bootstrap, I liked it but I thought it would be a bit easier. I think maybe it was the documentation that gave me stress but with time it'll be like riding a bike or muscle memory. Some challenges though were:
1. **Line length** — my file lines grew with all the shorthand code that I frequently got lost while trying to find my place.
2. **Grid/Flex** — I'm still getting used to flex in css and I feel as though there are more prereqs to get flex to work right, I might be mistaken though.
3. **Adding color**— this was interesting and limited

With Tailwind, the customizability of it was great and the [tailwindcss documentation](https://tailwindcss.com/docs/styling-with-utility-classes#complex-selectors) was easy to track in addition to https://tailwind.build/classes.


## 2. How did using Bootstrap utility classes and components simplify your styling process?
Though my line length is long the code itself is very short, only 37 lines of code, so the utility classes helped simplify a great deal. I'm a fan of shorthand and so the utility classes helped there, once I spend more time with them I'll be better at it.


## 3. In what scenarios might you choose not to use Bootstrap and write custom CSS instead?
I would most likely use custom CSS over Bootstrap when it comes to colors because Bs is very restrictive—I'd look into css variables though, which may help the rigidity. Also my symantic html attempts disappeared because I'm not sure if I can add multiple classes to one element so if I were looking at the code, I'd have a hard time finding out what code is what on the page—I need to add comments.
